# Project note

This repository is a public portfolio summary of a Medical Physics coursework project completed at the University of Edinburgh in March 2026.

The original report studied photon and charged-pion depth-dose distributions in water and water-bone-water phantoms using the Geant4-based EdMedPhysics framework.

The full submitted report is intentionally not included because it contains a student identifier and references to course-provided software/material. Selected quantitative results and figures are included with attribution to the project workflow.
